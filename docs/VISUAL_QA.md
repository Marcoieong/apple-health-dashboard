## 最終目視檢查

- iPhone 15 Pro（393×852）：今日與輸入頁無水平溢出，底部導覽可見。
- iPhone Pro Max（430×932）：內容自然加寬，觸控區未壓縮。
- iPad（768×1024）：主要內容置中，圖表及表單無截斷。
- Desktop 1366×768、1920×1080：左側導覽固定，主內容有合理最大寬度。
- 深色模式：背景、文字、邊框、進度條及珊瑚警示維持足夠對比。
- 瀏覽器 E2E 以 DOM 寬度斷言 `scrollWidth <= clientWidth + 1`。
- `prefers-reduced-motion` 會停用 smooth scroll／transition；圖表動畫停用以提升穩定與可讀性。
