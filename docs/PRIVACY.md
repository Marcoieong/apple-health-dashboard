# 隱私說明

## 第一階段資料流

個人健康 Dashboard 是純前端應用。健康紀錄保存在開啟網站之瀏覽器的 `localStorage`，不會由本專案主動傳送至伺服器或第三方。

- 沒有帳戶系統
- 沒有分析追蹤工具
- 沒有廣告
- 沒有健康資料遙測
- 沒有 Apple Health／HealthKit 連線
- 沒有把輸入內容寫入 console 的程式碼

## 使用者責任

匯出的 JSON 與 CSV 會包含敏感個人資料。使用者應把檔案存放在受密碼、裝置鎖或加密保護的位置，並避免傳送至不受信任服務。

瀏覽器資料可能因清除網站資料、私密瀏覽、儲存空間管理或更換網域而消失。請定期匯出 JSON 備份。

## Demo Data

首次開啟時建立的 14 日記錄為程式內的虛構示例，介面會顯示「Demo Data」。它不是 Apple Health 資料，也不代表任何真實個人的健康狀況。個人輸入與匯入紀錄會標記為不同來源。

## 健康資訊聲明

本工具只協助記錄習慣和檢視趨勢，不提供疾病診斷、治療、處方或緊急醫療建議。任何健康疑慮應由合資格專業人士評估。
